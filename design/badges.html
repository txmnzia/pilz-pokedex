Edibility as type badges

The handheld Pokédex marks each entry with coloured type badges. Here the five edibility states get that treatment, shown on the real Pilzdex surfaces at 375 and 320 px (iPhone SE). Colours borrow the type chart: edible = grass, no interest = normal, toxic = fire red, deadly = dark, unverified = the old "???" type.
