Ombres des boutons ATTRAPER / RETOUR

Aujourd'hui, les deux boutons ont une ombre dure rouge foncé décalée de 5 px vers le bas : on dirait une pastille collée sur une épaisseur rouge, pas un bouton en plastique. Sur un vrai Pokédex ou une Game Boy, le bouton est un dôme en plastique enfoncé dans un trou de la coque.

Appuie sur les boutons (ou sur « voir pressé ») pour comparer l'état enfoncé. Mêmes tailles que dans l'app.

Boutons PRÉC / SUIV (web)

Leur bordure est la même que les autres, mais sur l'accueil ils sont désactivés et tout le bouton passe à 45 % d'opacité : la bordure noire devient rose pâle. Correction : la bordure reste toujours noire, l'état inactif se voit par un jaune éteint.

Majuscules accentuées

Dans Press Start 2P, toutes les majuscules accentuées sont écrasées (la lettre rapetisse pour faire tenir l'accent dans la case) : É, È, Ü, Ö… Correction proposée : la vraie majuscule, avec un accent dessiné en pixels au-dessus, sans changer de police. Ça touche aussi l'allemand (ZURÜCK, TÖDLICH).
